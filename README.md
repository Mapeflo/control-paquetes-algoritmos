# Control de Paquetes - Algoritmos de Búsqueda

**Ejercicio 18** del taller de algoritmos de búsqueda.

## Descripción
Se implementa un sistema de control de paquetes utilizando un **arreglo de objetos** de la clase `Paquete`.  
Cada paquete tiene:
- Código de seguimiento
- Destinatario
- Estado

## Funcionalidades implementadas
- Búsqueda lineal por código de seguimiento
- Búsqueda de todos los paquetes con un estado determinado
- Ordenamiento por código de seguimiento (Bubble Sort)
- Búsqueda binaria por código de seguimiento
- Comparación de búsquedas exitosas y no exitosas
- Explicación de la complejidad temporal de los algoritmos

## Cómo ejecutar
1. Abre el proyecto en IntelliJ IDEA
2. Ejecuta la clase `ControlPaquetes`
3. Observa los resultados en la consola

## Complejidad temporal
- Búsqueda lineal: O(n)
- Búsqueda por estado: O(n)
- Ordenamiento (Bubble Sort): O(n²)
- Búsqueda binaria: O(log n)
